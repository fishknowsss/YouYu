常见问题

小白模式和专业模式要分别下载吗？
不用。标准版和无桌宠版都包含这两种模式，区别只在于是否包含桌宠。小白模式保留启停和状态反馈，专业模式提供节点、规则、TUN、测试与诊断等完整功能。
安装后怎么开始？
运行安装包并完成使用登记，在设置中保存自己的订阅，然后启动代理。安装需要管理员授权，日常运行使用普通用户权限。
停止后仍无法联网？
先在设置中执行“修复”，清理系统代理、WinHTTP 和 DNS 缓存。需要重建整个应用进程时，再使用托盘的“网络修复”。
版本会自动更新吗？
支持在应用内检查、下载、校验并安装更新，标准版和无桌宠版分别更新。旧版无法完成更新时，可从本页下载安装包覆盖安装。
安装时遇到 Windows 提示怎么办？
当前安装包尚未配置生产代码签名。请从本页链接的官方 GitHub Release 下载，并核对发布者仓库和 SHA256 清单；确认来源后再按 Windows 提示操作。
如何贡献或报告问题？
一般问题与改进建议可在 GitHub Issues 提交。安全问题请按安全策略私下报告，避免公开订阅和凭据。
