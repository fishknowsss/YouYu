# YouYu 1.5.9

YouYu 1.5.9 集中修复代理生命周期、身份隔离、系统代理恢复、覆盖安装和流量同步中的边界问题，并强化 Worker、D1 迁移、公共构建和仓库安全。此版本不修改前端界面或交互，升级后原有使用方式保持不变。

## 用户可见改进

- 点击停止后，旧的后台刷新、健康检查或恢复任务不会再次启动代理。
- 应用退出、重启和安装更新前会按统一顺序完成清理；清理失败时恢复运行，安装器启动失败时可直接重试已下载更新。
- 覆盖安装只关闭当前安装路径中的 YouYu 进程，避免影响另一份安装。
- 强制关闭前只恢复由 YouYu 实际接管的系统代理，降低更新后系统仍指向已退出本地代理端口的风险。
- 用户或设备身份发生变化时，流量、远程配置和远程订阅会切换到对应身份；设备失效后会停止代理并清理远程订阅。
- 流量上报在网络抖动、响应丢失和重试场景下保持幂等，减少漏计或重复累计。

## 服务端与工程改进

- Worker 的激活、登记和限流改为并发安全的原子流程，并补齐失败回滚与竞态测试。
- 请求体和远程配置增加明确的大小、数量和长度上限，无效配置会返回错误而不是静默忽略。
- D1 迁移工具支持只读检查、执行预览和显式应用；写入前会验证核心表、列、主键、唯一约束和索引，降低结构漂移导致的数据风险。
- 应用运行意图、重启、启动任务、远程订阅、流量登记和身份交接拆分为独立模块，减少生命周期逻辑互相覆盖。
- Windows 三通道构建使用统一的构建模式与发布编排；GitHub Actions 增加仓库卫生、Worker、标签版本和公开包订阅校验。
- Git 历史清除 Wrangler 本地数据库、历史内部构建与生成缓存；历史内的旧订阅值已确认失效，历史本地设备身份与生产数据无匹配项。

## 下载说明

GitHub Release 提供三个独立的 Windows x64 更新通道：

| 通道 | 安装包 | 桌宠 | 内置订阅 |
| --- | --- | --- | --- |
| 标准版 | `YouYu-1.5.9-x64.exe` | 有 | 无 |
| 内部更新通道版 | `YouYu-1.5.9-x64-in.exe` | 有 | 无 |
| 无桌宠通道版 | `YouYu-1.5.9-x64-no.exe` | 无 | 无 |

公开 `-in` 名称表示独立更新通道，不表示安装包携带私有订阅。三个公开安装包都需要用户自行配置订阅。

## 升级建议

- 可以直接覆盖安装原有版本；安装程序会先处理当前安装路径中的 YouYu 进程和其实际接管的系统代理。
- 正在运行代理时建议保存未完成的工作，再开始安装更新。
- 若更新后仍无法联网，可打开设置页执行“修复”，再检查其他代理软件、VPN、网卡和系统网络设置。
- 使用远程流量同步的用户无需重新登记；只有服务端明确判定设备失效时才需要重新登记。
