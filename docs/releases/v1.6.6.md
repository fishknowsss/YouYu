# YouYu 1.6.6 迭代说明

YouYu 1.6.6 统一专业模式页头操作，收紧诊断日志的长期运行行为，并完成流量后台的布局、设备识别、用户合并与规则配置重构。

## 专业模式与诊断日志

- 节点页和设置页移除重复的右上角返回按钮，继续使用左侧分栏完成页面切换。
- 专业模式各页的右上角操作按钮统一为 112×40px、16px 字号，并使用与左侧分栏悬停态一致的颜色。
- 诊断日志继续保留最多 200 个逻辑条目；两分钟内重复出现的同类日志会合并计数并保留起止时间，避免高频重复信息挤掉关键上下文。
- 导出日志使用完整日期时间，并附带容量与已丢弃条目数；单条异常信息限制为 4096 字符，避免异常输出无限膨胀。

## 后台管理页面

- 后台页面重构为用户工作台、详情上下文栏、全局配置、流量与异常视图，统一信息层级、表单布局、状态反馈、响应式和键盘焦点表现。
- 新增用户合并预览与确认流程，可选择保留目标用户配置、使用来源用户配置或恢复全局配置；设备、流量、异常和配置会在同一事务中迁移，旧登记身份继续作为别名可用。
- 用户列表同时区分逻辑设备数与历史登记记录数；新版客户端使用注册表中持久化的随机设备标识复用同一设备，不采集硬件指纹。
- 合并、流量上报与用户配置保存增加并发和幂等保护，避免合并瞬间漏账、重复执行或复活旧用户配置。
- 打包环境中的客户端版本改由 Electron 运行时提供，避免后台收到 `0.0.0`。

## 规则配置精简

- 后台与客户端仅保留“智能规则”和“机场规则”。原“智能规则”以成熟的内置规则集为默认；“机场规则”保留订阅提供的规则并补充必要的安全兜底。
- 旧“本地规则”和“全局代理”配置迁移为“智能规则”；旧字段仍可被旧客户端协议解析，但不再影响运行。
- 删除后台直联/代理规则、启动节点、策略选择和异常阈值调节，统一使用客户端本地选择及固定安全默认值。

## 验证范围

- 桌面端与 Worker 类型检查、自动测试、ESLint、Prettier、生产构建及 Worker dry-run 构建。
- 用户合并的别名链、配置冲突、请求幂等、并发合并、并发流量上报和并发配置保存。
- 专业模式 `900×600` 实际渲染；后台桌面、窄屏和移动端实际渲染、交互、溢出与控制台检查。
- Windows 本地三安装包与公开更新三安装包的内容隔离、反向解包和冒烟验证。
