# YouYu 1.6.8 迭代说明

YouYu 1.6.8 统一桌面端字体与专业模式排版，并更新 Electron 和 Mihomo 运行时。

## 字体与专业模式排版

- 渲染器统一使用 `system-ui, sans-serif`，按钮、输入框、选择框和文本框继承同一字体。诊断日志、出口 IP 与耗时不再切换到等宽字体，避免中英文和数字混排时出现后备字形差异。
- 界面字重收敛为系统实际支持的 700；caption、正文、操作和小标题使用明确的字号与行高。原有 11px 小字调整为 12px / 16px，单位行高只保留给桌宠睡眠状态的装饰性 `Z`。
- 专业模式首页右上角按钮与运行状态统一为 16px 字号、20px 行高、700 字重和 112×40px 尺寸，不再由状态组件单独覆盖字号。

## 测试页结构

- 测试表表头与数据行共享同一八列网格，表头、状态、出口信息、耗时和策略链使用一致的字体基线；服务名继续保留正文层级，“重测”按钮高度提高到 24px。
- 表格补齐 `rowgroup`、`columnheader` 和 `cell` 语义，操作按钮继续保留原生按钮角色；首页运行状态使用 `role="status"` 与非打断式播报。

## 运行时安全更新

- Electron 从 `39.8.9` 更新至 `43.2.0`，纳入当前稳定版运行时的安全修复与兼容性更新。
- 内置 Mihomo 更新至官方 `v1.19.28` Windows amd64 `with_gvisor` 构建。二进制版本、官方资产地址、来源归档和摘要由 manifest 与 `SOURCE.md` 固定记录，避免使用 `latest`、Alpha 或第三方镜像替代发布输入。

## 交付前校验

- 渲染器回归覆盖系统字体、受支持字重、明确行高、页头共享规格、测试表共享网格和 ARIA 表格语义。
- 在 `900×600` 默认窗口核对首页页头、测试表列线、小号状态、“重测”操作高度、混排字体落字和页面溢出。
- 校验 Electron 版本锁定、Mihomo 版本输出与来源信息，并按既有流程检查 Windows 本地三安装包和公开三更新通道的内容隔离。
- Electron 官方缓存与 Mihomo 对应源码归档支持完整哈希验证后的本机复用；缓存缺失时使用有界重试，避免一次短暂 GitHub 连接抖动直接中断 Windows 发布构建。
