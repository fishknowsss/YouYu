# YouYu 1.5.11

YouYu 1.5.11 将托盘中的两种网络修复合并为一个明确入口，并增强专业模式设置页的进程内修复。此版本同时加入诊断日志导出与常见问题建议，修复圆环静止以及设置页成功状态进入首页诊断区域的问题。

## 用户可见改进

- 托盘不再用子菜单分别显示“重启内核并重启软件”和“重型网络修复”，统一为单一“网络修复”。
- 托盘修复会先完成彻底清理，不在旧进程中间启动一次内核；随后退出并重启 YouYu，再由新进程启动新内核。
- 专业模式设置页仍使用“修复”按钮，整个过程不重启 YouYu。原本运行时会使用新端口重启 Mihomo，原本停止时保持停止；即使状态为失败，只要仍有有效运行意图，也会尝试恢复运行。
- 修复状态与使用登记状态中的圆环恢复可见旋转；系统启用“减少动态效果”时仍会停用动画。
- 专业模式设置页显示当前会话诊断日志条数，并提供“导出”按钮；导出的 UTF-8 文本已经脱敏，可直接用于问题定位。
- 设置页的“已同步”“已保存”“已修复”只在本页短暂显示，不会进入首页诊断区域。
- 设置页诊断行会根据最近一次 `lastError` 以红色显示“常见问题类型 · 建议操作”；修复时先执行对应的低风险预处理，再继续完整重型修复，成功后清除旧错误提示。

## 诊断日志导出

设置页显示的是当前会话可导出的诊断日志总数。导出报告最多包含当前会话 200 条记录，并附带应用版本、构建通道、运行状态和系统版本等必要环境信息；关闭并重新打开 YouYu 后，不会把这些记录作为历史日志继续累计。

报告采用字段白名单，并在写入 UTF-8 文本前再次脱敏。完整订阅、订阅地址、口令、设备密钥、后台凭据等敏感设置不会写入报告；日志中可能出现的用户目录、令牌和认证信息也会被替换。用户取消保存时不会生成文件，也不会显示错误。

诊断行中的问题类型与建议操作来自对最近错误的归类。系统代理问题会先关闭并复核当前用户代理，DNS 和一般连接问题会先刷新 DNS，内核问题会先安全关闭代理再停止旧内核，订阅问题会在内核运行时先尝试刷新订阅。预处理单项失败会记录诊断并继续同一套确定性的完整安全修复链；用户主动取消时则立即停止。分类不会触发 Winsock、TCP/IP、DHCP 重置或其他高风险操作。权限、后台或登记问题需要用户按页面建议处理，不会伪装成能够自动修复。

## 具体修复内容

设置页与托盘入口共用同一套分阶段清理：

1. 暂停可能重新拉起 Mihomo 或改写运行状态的后台任务，并记录修复前的运行意图。
2. 关闭 WinINet 系统代理、通知 Windows 配置已变化，并回读确认代理已经关闭。
3. 在系统代理确认安全后停止 Mihomo，避免 Windows 继续指向已经退出的本地代理端口。
4. 清理 WinINet 代理服务器与绕过列表、WinHTTP 代理和 DNS 缓存，修复 Microsoft Store 回环豁免，并检查原生命令的执行结果。
5. 删除 Mihomo 的易失 `cache.db`，保留订阅、用户设置、流量数据和其他持久配置。

设置页修复完成后会留在当前 YouYu 进程中，并按原运行意图决定是否使用新端口启动 Mihomo。托盘修复不会执行这次中间启动，而是直接重启 YouYu，再由新进程启动新内核。

针对性预处理只使用可重复执行的低风险步骤，失败时会记录诊断并继续完整修复。完整修复步骤仍固定且可验证，成功后会清除最近错误，避免旧分类继续显示。

## 适用范围

这套修复主要处理 YouYu 相关的系统代理残留、指向失效本地端口的代理、WinHTTP 代理残留、DNS 缓存、Microsoft Store 回环配置、Mihomo 易失缓存、内核卡死和端口异常。相比只刷新 DNS 或只重启内核，它覆盖了 YouYu 从 Windows 代理到 Mihomo 运行时的完整链路。

修复不会执行 Winsock、TCP/IP 或 DHCP 重置。这些操作可能影响 VPN、虚拟网卡和静态 IP 配置，通常还要求重启 Windows，不适合作为应用内的一键修复。网卡驱动、路由器、运营商网络或其他代理软件造成的问题仍需单独排查。

## 工程改进

- 将 WinINet 代理关闭作为停止 Mihomo 前的关键安全阶段；关键阶段失败时不会继续关闭内核，避免制造失效代理。
- 对 WinINet 启用和关闭结果、Microsoft Store 回环豁免及原生命令退出状态增加校验，补充操作失败时的明确错误传播。
- 修复期间暂停后台刷新、健康检查、流量任务和运行时恢复，降低修复过程中内核被意外重新拉起的风险。
- 设置页使用运行意图而不是瞬时状态决定修复后是否恢复 Mihomo，使失败状态下的有效运行意图也能被恢复。
- 仅清理 Mihomo 的易失缓存，不删除订阅、设置或统计数据。
- 诊断导出只从主进程的当前会话日志缓冲区生成报告，以字段白名单限制环境信息，并在保存前统一执行文本脱敏。
- 设置页操作结果与首页诊断状态分开维护：“已同步”“已保存”“已修复”只在设置页短暂显示，真实错误仍由诊断区域呈现。
- 常见问题分类只读取 `lastError`，用于选择低风险预处理和生成建议；完整修复链保持固定，并在成功后以比较后清除的方式移除原错误，避免并发产生的新错误被误删。

## 下载说明

GitHub Release 提供三个独立的 Windows x64 更新通道：

| 通道 | 安装包 | 桌宠 | 内置订阅 |
| --- | --- | --- | --- |
| 标准版 | `YouYu-1.5.11-x64.exe` | 有 | 无 |
| 内部更新通道版 | `YouYu-1.5.11-x64-in.exe` | 有 | 无 |
| 无桌宠通道版 | `YouYu-1.5.11-x64-no.exe` | 无 | 无 |

三个公开安装包都使用空内置订阅。公开 `-in` 名称只表示独立更新通道，不表示安装包携带私有订阅。

本地交付会另外保留带私有订阅的 `-in`、`-no` 双包及对应 `.blockmap`，存放在 `local-subscription-builds/1.5.11/`。该目录不包含标准版，只在本机长期留存，不提交、不上传 GitHub，也不作为公开更新资产来源。

## 升级建议

- 可以直接覆盖安装原有版本，现有订阅、节点选择、流量统计和运行设置会继续保留。
- 日常修复优先使用专业模式设置页“修复”；需要连同 YouYu 进程一起重建时，再使用托盘“网络修复”。
- 修复期间会暂时停止 Mihomo。设置页按原运行意图决定是否在当前进程中恢复；托盘入口会重启 YouYu 并启动新内核。
