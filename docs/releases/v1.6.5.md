# YouYu 1.6.5 迭代说明

YouYu 1.6.5 改善 Steam 路径的偶发探测失败，让两类批量测试都保留可中断或切换的控制权，并统一专业模式页头与首页面板的对齐规则。

## Steam 路径增强

- 当前实测曾复现 Steam 云同步路径的 TLS 握手超时；测试请求已通过本地 Mihomo 代理发出，因此根因不能简化为 Windows DNS 问题。本版同时收紧 DNS、探测负载和瞬时故障处理。
- Steam 商店从完整首页改为 `robots.txt` 轻量探测；Steam 商店、联机与云同步按顺序检查，避免三条 TLS 连接同时放大弱节点抖动。
- DNS、TCP、TLS 握手、连接重置等瞬时故障会重试一次；证书校验失败不会无意义重试。失败详情会标明所在阶段，便于区分节点路径与配置问题。
- Steam 域名改用跟随 Mihomo 分流规则的 Cloudflare / Google DoH，避免与实际节点出站脱节；DNS 缓存使用 ARC。手动切换、自动选优或健康检查切换成功后，会先关闭旧连接，再调用 Mihomo 控制器刷新 DNS 缓存。

SteamCommunity 302 的完整加速依赖本地反向代理、Hosts / DNS 重定向、根证书和端口接管。YouYu 只借鉴其域名定向、轻量健康检查与 DNS / TCP / TLS 分阶段诊断，不引入根证书、Hosts 劫持、80/443 端口占用或 WinDivert。这些做法会扩大权限和安全边界，也可能与 YouYu 现有 Mihomo 系统代理架构冲突。

## 可控的测速与测试

- 节点页全部测速时，节点主按钮保持可用，可以直接切换节点；为避免重复任务，单节点测速和更新订阅仍保持禁用。
- 全部测速返回的旧快照不会覆盖用户稍后完成的节点切换。
- 测试页“测全部”运行后原位切换为“停止”；点击后会通过请求 ID 取消当前 curl 子进程、清除测试中状态，并且不再启动队列中的后续网站。

## 专业模式对齐规则

- 首页、节点、测试和设置页共用 `WorkspaceHeader`；右上按钮与状态组件统一为 40px 行高，宽度按各自文案和用途保留差异。
- 四页操作区共用相同的上边界、右边界、底边界和正文间距，批量按钮保留 88px 最小宽度，“测全部 / 停止”切换不会造成位置跳动。
- “运行数据”与“诊断”共用 `DashboardPanel`，两个面板统一为 12px 纵向、14px 横向内边距、18px 标题轨和 8px 正文间距。

## 自动安装交接

- 点击“安装”后，小白模式更新卡与设置页更新行都会继续显示，明确告知“已开始自动安装，无需操作”，并显示即将重启状态。
- 完成旧进程与代理清理后，界面仍保留 2 秒阅读时间，随后才启动静默安装器；成功后按原有流程自动启动新版本。
- 2 秒交接缓冲期内会拦截窗口关闭、应用退出与托盘退出，避免提示刚出现就因进程提前结束而丢失安装任务。
- 安装器未能启动时，界面恢复为“安装未开始，请重试”并重新开放安装按钮，已下载更新包不会丢失。

## 验证范围

- Steam 三项探测顺序、轻量 URL、瞬时故障重试、证书失败不重试、DNS 策略和 Mihomo DNS 缓存 API。
- 节点测速期间切换、旧快照保护、测试页取消请求与队列停止。
- 首页面板标题和四页页头结构回归；`900×600`、`920×600`、`921×600` 真实渲染几何与溢出检查。
- 小白模式与设置页安装提示、2 秒延迟交接、失败重试和原有静默安装参数。
- README 六张 `900×600` 截图的 `1.6.5` 版本标识、当前 15 项测试数量、RFC 文档保留地址与虚构策略链。
- 桌面端与 Worker 类型检查、测试、ESLint、Prettier、生产构建、Windows 三包结构、内置订阅隔离和安装包冒烟检查。
