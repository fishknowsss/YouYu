# YouYu 1.7.6 迭代说明

YouYu 1.7.6 统一后台与客户端对“谁在管理配置”的认知。专业模式用户修改订阅或规则后，改动不再只留在本机，而是通过当前设备签名回传云端，并立即成为该用户的单独配置。

## 配置归属

- `跟随全局`：用户没有覆盖，自动和手动同步都采用后台最新全局配置。
- `单独配置`：客户端专业模式或后台用户抽屉保存了不同值，该用户使用自己的覆盖。
- `仅本机`：客户端尚未登记或没有可用云端配置，设置只保存在当前设备。

设置页直接显示当前归属，并显示真正传给 Mihomo 的有效规则。此前页面可能显示本机选择，而运行时优先采用云端规则；这一分叉已移除。

## 同步与冲突

客户端保存订阅或规则时，先完成设备签名的云端写入，再保存本机设置并按需重启运行时。云端写入失败时不会把冲突值伪装成已经保存。

后台将用户改为跟随全局后会移除用户覆盖。客户端下次自动或手动同步时取得最新全局值；如果客户端之后再次主动保存不同值，则重新成为单独配置。后台与客户端同时操作时，以 D1 最后成功提交的写入为准，不依赖可能漂移的客户端时钟。

## 安全边界

客户端写入必须使用当前设备密钥对完整请求体签名，只允许修改专业模式现有的订阅和规则来源。启停状态、地区策略及其他后台字段不能由客户端写入。后台读取、重置和全局清除覆盖仍需管理员令牌。

## 验证范围

- 签名客户端写入、非法签名和越权字段拒绝；
- 客户端改动生成用户覆盖，后台重置恢复全局，交替写入按最后成功提交收敛；
- 云端失败不落盘，仅修改 TUN 等本机设置不生成用户覆盖；
- 设置页归属文案、远端管理下可编辑，以及客户端显示值、缓存和 Mihomo 运行时一致；
- Worker、桌面端类型检查、测试、lint、格式、生产构建、Windows 安装包和公开更新资产闭环。
