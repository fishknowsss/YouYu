# YouYu 1.7.1 迭代说明

YouYu 1.7.1 将逐用户通知从“后台有一条数据”完善为可见、可确认、可追踪的桌面体验，并把客户端版本盘点和后台编辑收口为可部署的端到端流程。本版仍保留 1.7.0 的自动更新新鲜度保护：已下载旧包不会阻止发现更高版本，手动 Team Build 覆盖安装不被误当作自动更新验收。

## 独立通知窗口与位置

- 通知不再挤在主界面或桌宠窗口内部，而是由主进程创建独立的透明 `336×188` 工具窗口。窗口不进入任务栏、不抢占主窗口焦点，且只开放快照读取与当前修订确认 IPC。
- 标准版和无桌宠版固定定位到**主显示器工作区右下**，保留任务栏与显示器边缘的安全间距。
- 桌宠版按桌宠真实位置布局：桌宠贴底时通知优先显示在其上方；贴左时显示在右侧，贴右时显示在左侧；角落以底边优先，通知始终尝试避开桌宠并约束在所在显示器工作区内。桌宠所在显示器进入全屏抑制状态时，通知一并隐藏。
- 通知卡片只支持“提示”和“警告”，长文本在卡片内部滚动；“知道了”确认的是当前设备的当前修订，不会影响其他设备，也不会阻止下一次内容修订送达。

## 同步节奏

- 远程配置常规每 **3 分钟**拉取一次。
- 主窗口恢复/获得焦点、托盘重新打开主窗口、渲染器收到浏览器 `online` 事件时，会额外立即请求一次同步。
- 这些即时触发受 **12 秒**冷却合并，避免同一次前台恢复和网络恢复产生并发请求。

这是设备认证后的拉取，而不是后台常驻推送：网络不可用、设备没有运行或服务器不可达时，通知会在下一次成功同步时出现，不承诺毫秒级或绝对实时送达。

## 后台用户版本与资料管理

- 激活、签名配置拉取和签名流量上报都会记录客户端声明的版本；用户列表选择最近一条含版本的设备记录，返回 `latestAppVersion` 与 `appVersionReportedAt`。
- 版本列用于盘点，明确标注为“最近上报”，不能等同于在线状态。`1.7.1` 及后续内部/无桌宠构建分别上报 `1.7.1-IN`、`1.7.1-NO`；较旧客户端可能只显示其原有版本字符串。
- 用户名编辑仍只改变权威显示名。稳定用户 ID、设备、流量、订阅和 Mihomo 运行状态都不会因为改名而更换；原名称继续保留为别名，防止旧客户端再次创建重复用户。

## 定向通知的持续时间与重试

- 后台编辑器使用持续时间，默认 **10 分钟**，最小 **5 分钟**，按 **5 分钟**增减，最长 **7 天**。
- 服务器在保存时计算最终 `expiresAt`，因此客户端时钟错误不会提前或延后通知到期。新的保存请求会重新计时并推进修订。
- 每次保存携带 UUID `requestId`。因网络中断重试同一请求 ID 且内容相同，会返回原结果而不会重复推进修订或重置计时；复用该 ID 但内容不同会得到冲突响应。
- 旧的 `expiresAt` 写入字段被拒绝，避免浏览器把本地绝对时间误当作服务器时间。消息仍为最多 500 字符的纯文本，不能携带 HTML、链接、命令或远程操作。

## Team Build、手动安装与自动更新

- `npm run dist:win:local` 生成的私有 `-in` / `-no` 包只放在本机 `team-builds/`，用于人工交付；直接运行它们是手动覆盖安装，不等于自动更新通道已经通过验收。
- 自动更新仍按标准、内部、无桌宠三个公开通道分别读取 `latest.yml`、`latest-in.yml`、`latest-no.yml`。公开更新包不包含私有订阅，但覆盖更新不会清除既有本地设置。
- 手动覆盖安装前应通过托盘正常退出 YouYu。这样会按既有生命周期先恢复 YouYu 所有的系统代理设置，再停止 Mihomo，避免其他使用系统代理的应用短暂连接到已停止的本地端口。

## Worker 迁移与发布门禁

本版新增 `user_notice_audit` 表。生产部署顺序必须是：

1. 远端 `check` 与 `dry-run`；
2. 显式应用 `2026-08-02-add-user-notice-audit.sql`；
3. 再次 `check`；
4. 通过 Worker 类型检查、测试和构建后部署 Worker；
5. 验证用户版本列、改名、通知保存/重试、确认、到期与清除。

在迁移未完成前，不应部署依赖通知审计表的新版 Worker。

## 验证范围

- 桌面通知的主显示器、桌宠避让与边界几何；
- 通知小窗口的真实尺寸、可点击确认与无拖拽区域；
- 主窗口/托盘/网络恢复同步触发与冷却；
- 内部与无桌宠构建的版本上报标识；
- Worker 的时长校验、请求幂等、版本记录、用户合并与迁移预检；
- `900×600` 安全演示界面与 `336×188` 通知卡片截图。
