# YouYu 1.6.2 迭代说明

YouYu 1.6.2 收拢设置页底部布局，并补齐应用内静默更新与桌宠在 Windows 下的窗口边界处理。本次不改变桌宠造型、尺寸、配色或既有交互审美。

## 设置页

- “诊断日志”和“软件更新”统一为 54px 行高，右侧操作列统一为 130px，两个按钮均为 46px 高。
- “导出”和“检查”沿用软件现有按钮字体、字号和次级按钮表面，只把字重控制为略低于上方主要操作的 700，不再使用单独的小号轻字或透明背景。
- 在 900×600 最小窗口下，两行的左右起点、间距、按钮边缘和视觉节奏保持一致。

## 应用内更新

- 小白模式和专业模式继续共用同一条更新流程。
- 更新包下载完成后，用户点击应用内“安装”即可进入静默安装；软件会先完成现有退出清理，再无界面安装更新，并在安装成功后自动启动新版本。
- 手动下载或团队分发的安装包仍可按原方式独立运行；静默行为只作用于软件内已经下载完成的更新。

## 桌宠稳定性

- 桌宠窗口改为不可激活的 Windows 工具窗口，并在每次无焦点显示后重新应用任务栏排除策略，避免资源管理器或任务栏重建后偶发出现第二个桌宠预览框。
- 桌宠所在显示器出现真正的全屏应用时，桌宠立即隐藏并停止接收鼠标；其他显示器上的桌宠不受影响。
- 全屏退出后连续确认两次再恢复桌宠，避免游戏切换分辨率时闪现；如果用户原本主动隐藏桌宠，则不会被自动恢复。
- 全屏检测进程不可用时采用保持显示的保底策略，并只记录一次诊断信息，不会让桌宠永久消失。
- 全屏检测使用构建期生成的 7.5KB x64 本地辅助程序，并从安装资源复制到带完整性校验的版本化运行副本；不再为该功能常驻 PowerShell。
- 右睡状态的 `ZZZ` 跟随桌宠整体自然镜像，不再进行二次反向补偿；左睡动画保持不变。

## 验证范围

- 设置页 900×600 真实浏览器渲染、两行计算高度、按钮尺寸、字重和背景一致性。
- 应用内安装参数、退出清理和安装失败恢复路径。
- 桌宠工具窗口、不可激活、任务栏排除重应用、用户隐藏意图与全屏抑制状态。
- 同屏全屏立即隐藏、双采样恢复、异屏不隐藏、探测失败开放和进程退避重启。
- 左右睡动画镜像边界、完整主进程/渲染进程测试、类型检查、代码规范与 Windows 安装包校验。
