## 保持演示与软件一致

`site/demo.tsx` 直接渲染 `App`，使用原有 `useAppController`、页面和全部样式。网页仅用 `createDevYouYuApi({ preset: 'readme' })` 替代 Electron 接口，不另写侧栏、设置页、连接状态机或移动版软件布局。

- 独立 iframe 使用软件原始 900×600 视口；宽屏等比呈现，手机保留原尺寸并横向浏览。
- 场景导航位于软件外，切换时重挂载对应真实页面，内存 API 保留当前操作结果。
- 软件内部的节点选择、规则切换、TUN、保存、测试、模式入口及重新登记仍使用原有控制器。
- 父页只接受当前 iframe 和同源的已知消息；当前操作同步说明，运行状态同步网页桌宠。
- CSP 禁止网络连接；登记、订阅、测速、更新和导出使用内存示例，不修改系统网络，不保存真实输入。
- 滚动接近产品体验区时自动加载 React 演示，点击场景也可直接触发；首屏保留静态预览。加载失败保留截图与“重试”，不自动反复请求。

## 桌宠

网页浮动角色直接复用 `PetApp`、`PetSprite` 和图集，不复制另一套手势与动作状态机。浏览器桥接仅替代系统窗口移动、边缘范围和鼠标穿透；桌面版的“恢复主窗口”在网页中不执行跳转，双击只播放跳跃。

- 点击挥手、按住提起、横向行走、纵向拖动、双击跳跃使用实际逻辑。
- 松开时按照网页视口判断左右贴边、顶边休息、底边趴睡或下落恢复。
- 没有常驻操作条；展示区提供“收回桌宠”，右键、触屏长按和键盘菜单也可收回。
- 方向键可移动，Esc 收回。浏览器隐藏时卸载角色并清理计时；减少动态效果时取消位移动画、CSS 动画和帧变化。
- 网页内活动与安装版跨窗口桌面活动的边界，通过展示场景和使用指南说明。

## 维护入口

- 主页、共用导航及页脚：`docs/index.html`。
- 网站样式与行为：`docs/assets/site.css`、`site.js`、`showcase.js`、`pages.js`。
- 子页生成：`scripts/site-pages.mjs`；指南正文：`site/pages/guide.html`。
- 更新记录：只维护根 `CHANGELOG.md`；版本：只维护根 `package.json`。
- 修改网站内容后运行 `npm run site:sync`；修改演示或版本后运行 `npm run site:build`，提交生成结果。
- `npm run site:check` 同时核对四页、版本、下载链接和资源缓存标记。

验证围绕真实路径：原始界面比例、双模式、选点后首页同步、测试与设置、桌宠拖动/贴边/回收、导航与页内返回、手机横向浏览、减少动态效果、禁用 JavaScript 及加载失败。纯官网变更沿用 Pages 部署，不新增依赖、测试框架或 CI 阶段。
