# YouYu 1.6.1 迭代说明

YouYu 1.6.1 收紧专业模式的交互状态和设置页底部节奏，同时把私有团队安装包改成更适合手动分发的扁平双包目录。

## 登记与用户切换

- 后台已有姓名现在可以直接登记：服务端复用原 `userId`，因此该姓名已有的远程订阅、用户配置、累计用量和当日用量会继续使用，不再返回登记冲突。
- 同一安装环境会持久化一个设备种子；同一姓名重复登记保持原设备标识，不会重复增加设备。只有清空或损坏用户数据、切换 Windows 用户或改变用户数据目录时，才会被识别为新的逻辑设备。
- 专业模式左下角版本号是隐藏的重新登记入口。点击后普通页面完全退出，只保留居中的登记卡片；切换模式可以取消，不会把用户困在页面中。
- 切换前软件先停止采样，把旧用户尚未确认的增量上报到云端；任何结清失败都会中止切换并保留旧身份。
- 服务端确认目标用户后，本机清空旧用户的本地累计、今日数据、节点用量、待上报批次和远端缓存，再使用激活响应中的目标用户云端累计量和北京时间当日用量作为新基线，并同步该用户的远程配置。
- 新身份与云端累计/当日双基线通过一次原子写入落盘；激活响应不完整时会在改写本地身份前拒绝切换，避免出现“身份已换、基线未写”的半切换状态。
- 因此累计用量的口径是“目标用户云端累计 + 尚未被云端确认的当前增量”，今日用量的口径是“目标用户云端当日值 + 基线建立后的本地增量”；每次后台确认都会推进基线，旧用户数据不会复制、转移或重复计算。
- 云端激活是切换提交点：提交前失败会完整保留旧身份；提交后即使临时代理收尾、远程配置同步或内核重启失败，也保留已经生效的新身份与云端用量，并把后置异常写入诊断。

团队登记口令同时承担“选择已有姓名档案”的授权。姓名本身不是独立账号密码；知道共享口令的团队成员可以切换到已知姓名。口令应只在受信团队内分发，泄露后立即在 Cloudflare 中轮换。

## 专业模式界面

- 左侧选中项不再被普通浅色 hover 覆盖；悬停时只从品牌紫轻微加深，白字保持清晰。
- 当前页面增加 `aria-current="page"`，键盘焦点样式和按下反馈继续保留。
- 设置页“导出”和“检查”统一为 16px、低字重底部动作规格，按钮文字不再一重一轻。
- 软件更新行默认高度从 64px 收紧到 54px，与 46px 诊断行形成一个 8px 级差；两行左侧统一 14px 起点，右侧动作列统一为 130px。
- 下载进度、长错误或安装状态仍使用 `min-height` 自适应，不会因收紧默认高度而裁切。

## 团队安装包

`npm run dist:win:local` 成功后自动维护：

```text
team-builds/YouYu-1.6.1-x64-in.exe
team-builds/YouYu-1.6.1-x64-no.exe
```

- 目录固定只有当前版本两个带私有订阅的 EXE，不再分版本文件夹，也不保留旧版本或标准版。
- 新双包全部准备完成后才替换旧目录；构建、校验、冒烟或源文件检查失败时保留上一次可用双包。
- `team-builds/` 被 Git 忽略，并由仓库卫生校验禁止跟踪、提交或上传。

## `.blockmap` 的边界

`.blockmap` 是 electron-updater 的差分下载索引，用于在线更新时识别安装包中未变化的文件块。团队成员手动接收并双击完整 EXE 时不会读取它，因此不再放入 `team-builds/`。

公开 GitHub Release、`release/` 和 `release-archive/` 仍保留 `.blockmap`，自动更新能力不受影响。

## 验证范围

- 同设备同姓名幂等、已有姓名恢复配置、累计量和当日量、同设备切名、旧历史保留、切换失败回滚与目标云端双基线。
- 专业模式版本号入口、独立登记页、姓名预填、取消返回和切换状态。
- 私有双包扁平替换、失败保留、标准版与 `.blockmap` 排除。
- 专业模式五项导航默认、悬停、选中、选中悬停、按下和键盘焦点状态。
- 设置页常规、0/200 条诊断日志、导出中、更新检查、失败与下载状态。
- `900×600` 最小窗口下的行高、列线、右侧边缘和横纵向溢出。
- Windows 本地三包、私有双包内置订阅与安装包结构。
