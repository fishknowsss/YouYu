# YouYu 1.5.10

YouYu 1.5.10 修复完整订阅中明文健康检查地址引发的节点测速超时和 Mihomo 诊断警告。此版本不修改界面或操作方式，升级后无需重新配置订阅。

## 用户可见改进

- 常见 HTTP 204 健康检查地址会在 Mihomo 启动前转换为对应的 HTTPS 地址，降低自动选择节点时出现第二次测速超时的概率。
- 在线获取订阅和断网时读取本地缓存使用相同的规范化流程，重启后不会重新写回旧的明文探测地址。
- YouYu 管理的健康检查会确认目标返回 204，异常页或被替换的响应不会再被当作节点可用。
- provider 的订阅下载地址和机场自定义 HTTPS 健康检查保持不变。

## 工程改进

- 在完整订阅进入运行时配置的边界统一处理 `proxy-groups[*].url` 与 `proxy-providers.*.health-check.url`。
- 将 gstatic 与 1.1.1.1 两种已知 HTTP 204 地址分别映射到可靠的 HTTPS 探测地址，并同步设置 `expected-status: 204`。
- YouYu 自建的 provider 健康检查、自动选择、故障转移和负载均衡组统一要求返回 204。
- 新增完整订阅、在线获取、缓存回退、group/provider 交叉映射和自定义配置保留回归测试。

## 下载说明

GitHub Release 提供三个独立的 Windows x64 更新通道：

| 通道 | 安装包 | 桌宠 | 内置订阅 |
| --- | --- | --- | --- |
| 标准版 | `YouYu-1.5.10-x64.exe` | 有 | 无 |
| 内部更新通道版 | `YouYu-1.5.10-x64-in.exe` | 有 | 无 |
| 无桌宠通道版 | `YouYu-1.5.10-x64-no.exe` | 无 | 无 |

公开 `-in` 名称表示独立更新通道，不表示安装包携带私有订阅。三个公开安装包都需要用户自行配置订阅。

## 升级建议

- 可以直接覆盖安装原有版本，现有订阅、节点选择和运行设置会继续保留。
- 本次修复会在每次生成 Mihomo 运行时配置时自动生效，无需手动修改或删除 `config.yaml` 与订阅缓存。
- 若机场订阅使用自定义 HTTPS 健康检查，YouYu 会保留其地址和预期状态码。
