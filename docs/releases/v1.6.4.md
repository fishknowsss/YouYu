# YouYu 1.6.4 迭代说明

YouYu 1.6.4 修复开机自启同步的计划任务误判，收紧专业模式重新登记隐藏入口，并把设置页真正统一为一套连续六行布局。

## 开机自启同步

- Windows 任务计划程序会省略使用默认值的 `RunLevel`、任务 `Enabled` 字段，且允许不输出可选的 `Settings` 容器。旧版把这些省略项当作任务过期，随后尝试覆盖一个本来正确但当前用户没有重写权限的任务，因此出现“无法写入 Windows 计划任务”。
- 新版按照 Windows 默认语义读取这些字段。现有任务只要仍指向当前 YouYu、使用精确的 `--hidden` 参数、单一登录触发器和单一启动动作，就不会进行不必要的覆盖写入。
- 兼容默认字段没有放宽安全边界：复用检查仍要求普通交互用户，并拒绝高权限运行级别、服务账户、管理员组、内置管理员、非交互登录和显式附加权限。
- 本次解决的是“正确任务被误判后重写失败”的诊断路径；若未来实际需要删除或重建一个权限异常的任务，Windows 仍可能要求相应系统授权。

## 七击隐藏入口

- 专业模式左下角版本号保持普通版本信息外观，不再出现悬停变色、背景、边框强化或按压位移，也不在辅助名称中提示重新登记功能。
- 只有连续点击版本号 7 次才会进入独立的重新登记界面；前 6 次不会切换页面，第 7 次进入后计数立即清零。
- 版本号仍水平居中，并根据侧栏实际宽度计算底部留白。在 `900×600` 下外侧左距与下距均为 39.09px，在 `1280×900` 下均为 47.5px。

## 设置页六行网格

- 页面组件树统一为订阅、规则、后台刷新、TUN、诊断日志和软件更新六个直接子行，不再嵌套“主设置”和“页脚”两组独立网格。
- 唯一父网格使用六个 64px 轨道和五处 8px 间距；六行共享同一套第一内容列、204px 状态列和 130px 操作列。
- 输入框、选择器、按钮及底部状态条保留既有高度，在各自 64px 轨道内统一底对齐。页面没有增加说明文字、边框或装饰。
- `900×600` 默认窗口和 `1280×900` 宽窗口实测均为六行 64px、五处 8px，且没有横向或纵向溢出。

## 验证范围

- Windows 计划任务默认字段省略、可选设置容器、命令与参数匹配、登录触发器、普通交互用户和高权限主体拒绝。
- 版本号无悬停变化、前 6 次点击无动作、第 7 次进入重新登记，以及入口计数复位。
- 设置页六行结构、共享列线、行高、间距、按钮对齐、默认窗口与宽窗口边界。
- Windows 本地私有双包、公共三通道更新包、内置订阅隔离、安装包冒烟检查与远端 `latest*.yml` 更新链路。
