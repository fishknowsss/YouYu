# YouYu 1.6.7 迭代说明

YouYu 1.6.7 重构流量后台的信息架构与交互稳定性，并校正专业模式页头操作层级和桌宠预览边界。

## 后台管理页面

- 用户数据改为全宽主工作区，配置区改为稳定双栏，流量明细和异常数据使用全宽区域；保留原有管理内容、接口和操作流程。
- 用户表使用明确的九列宽度契约、固定表格布局和固定排序标记槽位，排序、刷新和选择用户不再改变表格及页面宽度。
- 页面根节点永久预留滚动条空间；令牌验证改为不参与文档流的页头浮层，选择用户不再自动滚动页面，按钮加载态和按下态不再改变组件尺寸或位置。
- 令牌浮层的未提交草稿不再参与后台请求；管理页禁止边缘自动注入统计脚本，缩小敏感会话页面的脚本信任边界。
- 桌面、窄屏和移动端分别使用完整数据表、单栏配置和紧凑用户卡片；移动端继续保留全部字段和八种排序能力。
- 统一中性画布、白色面板、细边框、40px 控件、状态色、焦点态、表格行高和响应式间距，减少重复阴影与嵌套容器造成的视觉噪声。

## 专业模式界面

- 首页“运行中”状态与“返回小白”统一为 112×40px，使首页双组件与节点页双操作严格对齐。
- 节点页“全部测速”和测试页“测全部”恢复为深色主操作；“更新订阅”等次要操作继续使用浅色悬停表面。
- 桌宠预览的状态卡、主预览和说明区域补齐与其他专业页面一致的 1px 细边框，切页时不再出现容器边界缺失。

## 验证范围

- Worker 与桌面端类型检查、自动测试、ESLint、Prettier、生产构建及 Worker dry-run 构建。
- 后台在 `1440×900`、`1190×900`、`900×600` 和 `390×844` 下逐项测试排序、选择用户、令牌浮层、页面滚动和横向溢出。
- 专业模式在 `900×600` 下核对首页、节点、测试和桌宠预览的按钮尺寸、颜色层级、边框与控制台输出。
- Windows 本地三安装包与公开更新三安装包的内容隔离、反向解包和冒烟验证。
