安装前了解一下

公开安装包不内置订阅，请准备自己的订阅地址。
安装时需要管理员授权，日常运行使用普通用户权限。

当前安装包尚未配置生产代码签名。
请从官方 GitHub Release 下载，确认来源后按 Windows 提示操作。
